# Validated scope and version boundary

## What is established at this checkpoint

The HF2007 public checkpoint establishes that the T0 path-legitimacy decision was compiled into executable pre-reasoning admission logic, bound to fixed public-source bytes, separated into reference and raw-only prediction paths, replayed deterministically, and preserved with machine-readable comparison and audit artifacts.

On the fixed 51-transition slice, the public package records 51/51 exact relation-vector matches, 51/51 outcome agreement, 17/17 admitted authorized controls and 34/34 stopped injected tool-output transitions. The package passed the review path that resulted in formal acceptance.

## Exact public scope

This evidence applies to:

- the byte-fixed InjecAgent commit and source files named in [`PROVENANCE.md`](PROVENANCE.md);
- the deterministic selection of 17 user, 17 direct-harm and 17 data-stealing transitions;
- the HF2007 relation rubric, frozen author reference decisions and supplied deterministic extractor;
- the result and replay artifacts inside the immutable experiment ZIP.

## Boundary of this version

The public slice contains two observed relation vectors. Five relations receive negative coverage and co-fail in all 34 stopped transitions; three relations receive no negative examples. A simple tool-output-origin blocking baseline produces the same admission counts on this slice, and no benign tool-derived continuation is present. Therefore this checkpoint does not measure low over-blocking for benign post-tool workflows or establish that the eight-relation vocabulary is an empirically minimal basis.

These are the boundaries of the public experiment, not evidence that the internal system ended at this layer. The full private system, later T0 engineering, SCBKR, AICC and Runtime integration are outside this artifact and continue under separate versions. This release makes no general guarantee for every prompt-injection or agent environment.

## Version rule

A later system version may extend the tested domains, relation coverage, benign continuations, cross-tool flows, responsibility paths and Runtime integration. It must receive a new manifest and new evidence. It must not rewrite this checkpoint or present later results as if they were contained in HF2007.
